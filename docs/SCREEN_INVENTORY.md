# Cross-Platform Screen Inventory

## 1. Cloud Web (Vercel)
- **Marketing Homepage**: Value props, Pricing Tiers, Call to Actions.
- **Auth Modal**: Login & Registration (email/password), Bruteforce protection UI.
- **Central Dashboard**: 
  - Device Mesh List (shows connected nodes).
  - Admin Governance Link (if authorized).
  - WebRTC Cloud Viewer (**Roadmap/Beta**).

## 2. Windows PC Agent (Native PyWebView)
- **Local Dashboard**:
  - Daemon Status Indicator.
  - Local Autonomous Agent Prompt.
  - Android Device Link (USB/ADB mirror launcher).
  - Terminal Event Log.

## 3. Android App (Tauri / React)
- **Remote Client UI**:
  - Connection Pairing (input code to link to mesh).
  - Device List (Windows Host vs Local Android Node).
  - Viewport (MJPEG / Polling stream).
  - Action/AI Prompt Bar (Control Windows from phone).
